# Clara Turns 25

Frontend statis untuk ucapan ulang tahun ke-25 **Clara Devinda Jaya Sutrisno**. Tidak membutuhkan framework, package manager, atau proses build.

## Menjalankan secara lokal

Buka `index.html` langsung di browser, atau jalankan static server:

```bash
python -m http.server 8080
```

Kemudian buka `http://localhost:8080`.

## Deploy ke GitHub Pages

1. Buat repository baru di GitHub.
2. Upload seluruh isi folder ini ke root repository.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main`, folder `/ (root)`, lalu **Save**.
6. Tunggu 1–3 menit hingga URL GitHub Pages tersedia.

## Mengubah teks

Edit ucapan di `index.html`. Warna dan layout berada di `styles.css`, sedangkan animasi confetti, tombol bagikan, lilin, dan suara berada di `script.js`.

## Mengganti visual

Ganti `assets/birthday-25.png` dengan PNG lain menggunakan nama file yang sama. Untuk hasil terbaik gunakan gambar transparan berbentuk portrait/square.
